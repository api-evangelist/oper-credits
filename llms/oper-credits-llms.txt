# Oper Credits

> Oper Credits is a Belgian digital mortgage origination platform (Brussels, founded 2019) that lets banks, lenders, and brokers offer and process end-to-end digital mortgages. The white-labelled, multi-tenant Oper Connect platform exposes a JWT-authenticated REST API organized around the loan request as the central object, plus a loan-request webhook surface and an AI underwriting agent ("Herman").

## APIs

- [Oper Mortgage API (core)](https://developers.opercredits.com/#/api): JWT-bearer REST API; loan requests and all nested resources (clients, realties, offers, documents, guarantees, decisions).
- [Oper resources API](https://developers.opercredits.com/#/api/resources): reference/lookup collections backing the mortgage domain.
- [Loan Request Webhook API](https://developers.opercredits.com/#/webhook): outbound webhook payload contract (versions 1.0-1.4).

## Specs

- openapi/oper-credits-api-openapi.json — core API (OpenAPI 3.0.3, 286 paths)
- openapi/oper-credits-resources-openapi.json — resources API (OpenAPI 3.0.3, 332 paths)
- openapi/oper-credits-metrics-openapi.json — metrics API (OpenAPI 3.0.3)
- openapi/oper-credits-loan-request-webhook-openapi.json — webhook payload (OpenAPI 3.1.0)
