Oper Credits is a Belgian digital mortgage origination platform (Brussels, founded 2019) that lets banks, lenders, insurers, and brokers offer and process end-to-end digital mortgages. Its white-labelled, multi-tenant Oper Connect platform exposes a JWT-authenticated REST API organized around the loan request as the central object, under which borrowers, properties, offers, documents, guarantees, and decisions are nested, plus a versioned loan-request webhook surface and an AI underwriting agent ("Herman") that automates document collection, extraction, verification, and policy analysis. The platform is ISO/IEC 27001 certified and GDPR compliant.

**Areas:** Company · Mortgage · Lending · Credit · Fintech · Banking · Loan Origination · Real Estate · Financial Services · Underwriting

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).
